{% load static %} {% comment %} Aladin Lite v3, from our own static files (#70; YSE_App/static/YSE_App/aladin-lite/3.8.2/README.md). Include once, anywhere in the page. It defines window.aladinReady, a promise of Aladin's `A` once its WebAssembly is ready, and window.aladinView(selector, options), which creates a viewer only if its survey answers (see below): window.aladinView('#div', {survey: 'https://.../DSSColor', fov: 0.017, target: '...'}); Why check the survey first: when a viewer's only survey fails (CDS down), Aladin 3.8.2 falls back to its default survey by name, which fails too, and falls back again, forever (`setBaseImageLayer(DEFAULT_OPTIONS .survey)` in a `finally`, no option turns it off). So the survey's small `properties` file is fetched once first, and if it doesn't answer within 5 s the box says so and Aladin is never started. The library is an ES module, so it loads deferred and never blocks rendering. If it fails to load, or the browser has no WebGL2, the promise is rejected (logged to the console) and nothing else on the page is affected: only the viewer stays empty. Sky tiles still come from CDS, after the page has rendered. {% endcomment %}
